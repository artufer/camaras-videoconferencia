# 📷 Control de Cámaras BCC950

App web para gestionar el préstamo de 3 cámaras Logitech BCC950 en el edificio de oficinas.

## 🚀 Acceso

🔗 **URL:** https://TU_USUARIO.github.io/NOMBRE_REPO/

## 📱 Instalación en el móvil

1. Abre la URL en Chrome (Android) o Safari (iPhone)
2. Chrome: Menú (⋮) → "Añadir a pantalla de inicio"
3. Safari: Botón compartir → "Añadir a pantalla de inicio"
4. ¡Listo! Aparecerá como una app normal.

## 🔧 Configuración Firebase (para sincronizar entre dispositivos)

1. Ve a https://console.firebase.google.com/
2. Crea un nuevo proyecto (gratis)
3. Activa "Realtime Database" en modo prueba
4. Copia la configuración en `index.html` (sección firebaseConfig)
5. ¡Los datos se sincronizarán automáticamente!

## ✨ Funciones

- ✅ Estado en tiempo real de las 3 cámaras
- ✅ Préstamos y reservas con fechas
- ✅ Calendario mensual visual
- ✅ Historial completo con filtros
- ✅ Informes por cámara y por persona
- ✅ Control de estado (funcionando/estropeada)
- ✅ Constancia de quién recoge y quién devuelve
- ✅ Sincronización entre dispositivos
- ✅ Funciona offline (modo local si no hay Firebase)
